# breach-game/.github

Files shared across the [breach-game](https://github.com/breach-game) organization. [BREACH](https://breach-game.github.io/breach/) is a cybersecurity thriller that runs in your browser.

| Path | Role |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The organization's profile page, with its screenshots in `profile/screens/` |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Code of conduct, used by every repository of the organization |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability, for repositories without their own policy |
| [`SUPPORT.md`](SUPPORT.md) | Where to get help |
| [`brand/`](brand/) | The complete visual identity (logo, wordmark, avatar, favicon, social preview) and its sources. See [`brand/README.md`](brand/README.md) |

GitHub shows the community files above in every repository of the organization that does not have its own copy.

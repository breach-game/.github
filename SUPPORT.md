# Getting help

- **Stuck in a mission?** In the game, use *Ask for a hint* in your notebook, or switch to the *Guided* level: Ada will give you each command. A hint only costs a few points.
- **Something does not work?** Open an issue in [breach-game/breach](https://github.com/breach-game/breach/issues/new/choose), with your browser and the mission.
- **A community mission is broken or inappropriate?** Report it in [breach-game/packs](https://github.com/breach-game/packs/issues/new/choose).
- **You want to write a mission?** Start with the [pack guide](https://github.com/breach-game/packs/blob/main/CONTRIBUTING.md).
- **A security problem?** Follow the [security policy](SECURITY.md), never a public issue.
